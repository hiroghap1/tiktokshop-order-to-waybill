# TikTok Shop Order to Waybill Converter

TikTok Shopの注文データ（CSV）を、各配送会社の送り状発行システム用CSVに変換するWebアプリケーション。

## 概要

TikTok Shopからエクスポートした注文CSVファイルをアップロードし、以下の配送会社のシステムに取り込み可能なCSVに変換します：

- **佐川急便 e飛伝Ⅲ**
- **ヤマト運輸 B2クラウド**

## 機能要件

### 基本機能

1. **CSVアップロード** - TikTok Shopからエクスポートした注文CSVをドラッグ＆ドロップまたはファイル選択でアップロード
2. **配送会社選択** - 変換先の配送会社（佐川 or ヤマト）を選択
3. **データプレビュー** - 変換前のデータを確認できるプレビュー機能
4. **CSV変換・ダウンロード** - 選択した配送会社形式のCSVを生成してダウンロード

### 追加機能（オプション）

- 発送元情報の設定・保存（ローカルストレージ）
- 複数ファイルの一括処理
- エラーデータのハイライト表示
- 変換履歴の表示

## 技術スタック

### フロントエンド（SPA）

- **React** + **TypeScript**
- **Vite** - ビルドツール
- **Tailwind CSS** - スタイリング
- **Papa Parse** - CSVパース・生成
- **React Dropzone** - ファイルアップロードUI

### バックエンド

- なし（クライアントサイドのみで完結）
- データはブラウザ上で処理され、サーバーに送信されない

## エラーハンドリング

### バリデーション項目

1. **必須項目チェック** - 配送先名、電話番号、郵便番号、住所が空でないか
2. **郵便番号形式** - 7桁の数字であるか
3. **電話番号形式** - 数字とハイフンのみで構成されているか
4. **文字数制限** - 各フィールドの最大文字数チェック

### エラー表示

- エラーのある行をハイライト表示
- エラー内容をツールチップで表示
- エラー件数をサマリー表示
